# Hackenbush 竹スタークゲーム（グラフゲーム理論）

竹（縦の辺の連なり）を持つHackenbushゲームの簡易版。

## 概要

- 3〜5本の竹スタックをSVGで描画（毎回ランダム生成）
- 辺をクリックすると、その辺以上（根から切り離される辺）が消える
- プレイヤー交互制（1P vs 2P、またはAIモード）
- 動ける辺がなくなった方が負け
- Nim値（Grundy数）に基づく局面分析表示
- AIはNim理論最適手選択（XOR合計を0にする戦略）

## 技術仕様

- Tailwind CDN + バニラJS + SVG描画
- XSSガード実装済み（escHtml関数）
- 全インタラクティブ要素にaria-label付与
- レスポンシブ対応
